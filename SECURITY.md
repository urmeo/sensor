# Security

This repository contains local Python scripts and a sample from one participant. It provides no network service. The raw Session 1 data and eye summaries from three sessions include sensitive observations.

## Reporting

Report security or privacy concerns through a [private security advisory](https://github.com/urmeo/sensor/security/advisories/new). Include the affected file path and a small synthetic example that reproduces the issue. Keep participant responses, identifying details and consent documents out of public issues. Privacy reports will be reviewed with the data controller.

## Supported version

Support covers the current `main` branch. Review [data ethics](DATA_ETHICS.md) and [rights](NOTICE.md) before sharing derived copies.
